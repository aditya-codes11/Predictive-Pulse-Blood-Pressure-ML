# Predictive Pulse: Harnessing Machine Learning for Blood Pressure Analysis

Predictive Pulse is a machine learning-based web application that predicts the stage of blood pressure using patient health parameters such as age, gender, systolic and diastolic pressure, medical history, and symptoms. The system helps in identifying potential hypertension risks through data-driven analysis.

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML, CSS

## Features
- Predicts blood pressure stage
- User-friendly web interface
- Accepts patient health parameters
- Provides instant prediction results
